
Так исторически сложилось что ветка для запуска нагрузочно тестирование во всех сервисах perf-test, но в монолите это roseu-perf-test

Как его настроить
2 варианта
Пустая база. Создать заявку в jira пример [DevOps](https://track.astral.ru/soft/browse/DEVOPS-2046) с текстом:
Необходимо создать базы для продолжения нагрузочного тестирования.

operator_2ae_master  
operator_2ae_utils_db  
operator_meta_db  
queue_2ae

**operator_2ae_master**  
Создать пустую базу, дать приложению подключиться. После подключения будет выполнена миграция, которая создаст таблицы.  
После выполнения миграции перенести из продовой базы оператора таблицы:

- users
- operators

**operator_2ae_utils_db**  
Создать и скопировать схему с прода Оператора

**operator_meta_db**  
Создать и скопировать схему с прода Оператора

**operator_core_db**  
Создать и скопировать схемы с прода Оператора

**queue_2ae**  
Создать и скопировать схему с прода Оператора
