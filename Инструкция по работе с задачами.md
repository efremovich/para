# Инструкция по работе с задачами

## Главная доска задач

Все планируемые действия из всех проектов собираются в [[Главная доска задач]].

## Структура задач

### Теги проектов
Используйте теги для категоризации задач по проектам:
- `#fuel-app` - проект топливных карт
- `#fuel-infra` - инфраструктура проекта fuel-app
- `#Astral` - проект Astral
- `#devOps` - задачи DevOps
- `#Nixos` - задачи по NixOS
- `#Разработка` - общие задачи разработки
- `#Развертывание` - задачи развертывания

### Даты
Используйте формат `@{YYYY-MM-DD}` для указания дедлайнов или приоритетных дат.

### Связи
Добавляйте ссылки на связанные файлы проекта через `[[путь/к/файлу]]`.

## Как добавлять задачи

### Из проектных досок
1. Скопируйте задачу из проектной доски
2. Добавьте соответствующие теги проекта
3. Добавьте ссылку на исходную доску

### Новые задачи
1. Откройте [[Главная доска задач]]
2. Добавьте задачу в соответствующую колонку
3. Укажите теги проекта
4. При необходимости добавьте дату и ссылки

## Проектные доски

- [[fuel-app/Доска проекта fuel-app]] - доска проекта fuel-app
- Можно создавать дополнительные доски для других проектов

## Фильтрация

В Obsidian можно использовать поиск по тегам для фильтрации задач:
- `tag:#fuel-app` - все задачи проекта fuel-app
- `tag:#devOps` - все DevOps задачи
- И т.д.
