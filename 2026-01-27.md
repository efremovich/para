## Docker Compose для BetAuto (PHP 5.6)

Создана Docker Compose конфигурация для запуска веб-сервиса PHP 5.6 для отладки приложения BetAuto (`/home/efremov/Dev/Holding/betauto`).

### Созданные файлы:
- `docker-compose.yml` - основная конфигурация с сервисами:
  - web (PHP 5.6 + Apache)
  - db (MySQL 5.7)
  - phpmyadmin
- `Dockerfile` - образ PHP 5.6 с Apache и необходимыми расширениями
- `docker/php/php.ini` - конфигурация PHP
- `docker/apache/000-default.conf` - конфигурация виртуального хоста Apache
- `.env.example` - пример переменных окружения
- `.dockerignore` - исключения для Docker
- `README.DOCKER.md` - документация по использованию

### Особенности:
- PHP 5.6 с Apache и mod_rewrite
- MySQL 5.7 для базы данных
- phpMyAdmin для управления БД
- Автоматический импорт SQL файлов из директории `sql/`
- Настроены расширения PHP: mysqli, pdo, pdo_mysql, gd, zip, intl, xml, mbstring

### Порты:
- Веб-приложение: http://localhost:8080
- phpMyAdmin: http://localhost:8081
- MySQL: localhost:3306
