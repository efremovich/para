# Маркетплейсы

## Интерфейс ExtAPIFetcher

Единый интерфейс для работы со всеми маркетплейсами определен в `internal/usecases/webapi/interface.go`:

```go
type ExtAPIFetcher interface {
    GetCards(ctx context.Context, desc entity.PackageDescription) ([]entity.Card, error)
    GetStocks(ctx context.Context, desc entity.PackageDescription) ([]entity.StockMeta, error)
    GetWarehouses(ctx context.Context) ([]entity.Warehouse, error)
    GetOrders(ctx context.Context, desc entity.PackageDescription) ([]entity.Order, error)
    GetSales(ctx context.Context, desc entity.PackageDescription) ([]entity.Sale, error)
    GetSaleReport(ctx context.Context, desc entity.PackageDescription) ([]entity.SaleReport, error)
    GetCosts(ctx context.Context, desc entity.PackageDescription) ([]entity.Cost, error)
    GetPromotion(ctx context.Context, desc entity.PackageDescription) ([]*entity.Promotion, error)
    GetMediaCampaigns(ctx context.Context) ([]*entity.MediaCampaign, error)
    
    // Платное хранилище
    CreatePaidStorageTask(ctx context.Context, desc entity.PackageDescription) (string, error)
    CheckPaidStorageTaskStatus(ctx context.Context, taskID string) (bool, error)
    DownloadPaidStorageReport(ctx context.Context, taskID string) ([]entity.PaidStorage, error)
    
    // Платная приемка
    CreatePaidAcceptanceTask(ctx context.Context, desc entity.PackageDescription) (string, error)
    CheckPaidAcceptanceTaskStatus(ctx context.Context, taskID string) (bool, error)
    DownloadPaidAcceptanceReport(ctx context.Context, taskID string) ([]entity.PaidAcceptance, error)
    
    DownloadReturnsReport(ctx context.Context, desc entity.PackageDescription) ([]entity.ReturnsReport, error)
    GetStockMetaReport(ctx context.Context, desc entity.PackageDescription) ([]entity.StockReportMeta, error)
    GetSalesFunnel(ctx context.Context, dest entity.PackageDescription) ([]*entity.SalesFunnel, error)
    DownloadSalesFunnelDetail(ctx context.Context, desc entity.PackageDescription, nmIds []int64) ([]*entity.SalesFunnel, error)
    DownloadSalesFunnelDetailHistory(ctx context.Context, desc entity.PackageDescription, nmIds []int64) ([]*entity.SalesFunnel, error)
    DownloadSalesFunnelGroupedHistory(ctx context.Context, desc entity.PackageDescription, nmIds []int64) ([]*entity.SalesFunnel, error)
    
    // Удержания
    DownloadAntifraudDetails(ctx context.Context, desc entity.PackageDescription) ([]*entity.DeductionsReport, error)
    DownloadIncorrectAttachments(ctx context.Context, desc entity.PackageDescription) ([]*entity.DeductionsReport, error)
    DownloadStorageCoefficient(ctx context.Context, desc entity.PackageDescription) ([]*entity.DeductionsReport, error)
    DownloadGoodsLabeling(ctx context.Context, desc entity.PackageDescription) ([]*entity.DeductionsReport, error)
    DownloadCharacteristicsChange(ctx context.Context, desc entity.PackageDescription) ([]*entity.DeductionsReport, error)
    
    Ping(ctx context.Context) error
    GetMarketPlace() entity.MarketPlace
}
```

## Реализации

### 1. Wildberries (`wbfetcher/`)

**Файлы:**
- `client.go` - основной клиент
- `card.go` - получение карточек товаров
- `orders.go` - заказы
- `sales.go` - продажи
- `saleReport.go` - отчеты о продажах
- `stocks.go` / `stock.go` / `stock_meta.go` - остатки
- `warehouse.go` - склады
- `promotion.go` - акции
- `media_compaing.go` - медиа-кампании
- `paid_storage.go` - платное хранилище
- `paid_acceptance.go` - платная приемка
- `returns_report.go` - отчеты о возвратах
- `sales_funnel.go` - воронка продаж
- `deductions_report.go` - удержания
- `raw_layer_repo.go` - работа с raw layer

**Особенности:**
- Использует Wildberries Open API
- Поддержка raw layer для кэширования
- Работа с различными типами отчетов

### 2. Ozon (`ozonfetcher/`)

**Файлы:**
- `client.go` - основной клиент
- `card.go` - получение карточек товаров
- `orders.go` - заказы
- `sales.go` - продажи
- `stocks.go` - остатки
- `warehouse.go` - склады

**Особенности:**
- Использует Ozon Seller API
- Работа с товарами, заказами, продажами

### 3. Yandex Market (`yandexfetcher/`)

**Файлы:**
- `client.go` - основной клиент и инициализация
- `card.go` - получение карточек товаров через offer-mappings
- `orders.go` - заказы через orders API
- `sales.go` - продажи (фильтр по DELIVERED статусу)
- `stocks.go` - остатки по складам
- `warehouse.go` - склады
- `http_client.go` - HTTP клиент с пагинацией
- `entity.go` - модели данных Yandex API
- `raw_layer.go` - работа с raw layer БД

**Особенности:**
- Использует Yandex Market Partner API
- Поддержка пагинации через `paginatedRequest()`
- Raw layer для кэширования данных
- Общая функция `getOrdersFromAPI()` для orders и sales
- Подробнее: [[data-receiver/YandexFetcher|Yandex Fetcher]]

**API эндпоинты:**
- `POST /businesses/{businessId}/offer-mappings` - список товаров
- `POST /businesses/{businessId}/orders` - заказы
- `GET /campaigns/{campaignId}/warehouses` - склады
- `POST /businesses/{businessId}/warehouses/{warehouseId}/stocks` - остатки

### 4. OdinAss (`odincfetcer/`)

**Файлы:**
- `client.go` - основной клиент

**Особенности:**
- Минимальная реализация
- Базовая поддержка интерфейса

## Общие паттерны

### 1. Raw Layer

Некоторые fetcher'ы (WB, Yandex) поддерживают raw layer - кэширование сырых данных от API в отдельной БД для:
- Ускорения повторных запросов
- Сохранения истории данных
- Снижения нагрузки на API маркетплейсов

### 2. Пагинация

Многие API возвращают данные постранично. Реализованы утилиты для пагинации:
- `paginatedRequest()` в yandexfetcher
- Обработка токенов следующей страницы

### 3. Конвертация данных

Каждый fetcher конвертирует данные из формата API маркетплейса в единые доменные сущности (`entity.*`):
- `convertOrdersToEntity()` - конвертация заказов
- `convertSalesToEntity()` - конвертация продаж
- `convertStocksToEntity()` - конвертация остатков

### 4. Обработка ошибок

- Проверка доступности API через `Ping()`
- Обработка ошибок API с сохранением контекста
- Логирование ошибок через alogger

## Конфигурация маркетплейсов

Маркетплейсы настраиваются через переменные окружения:

```env
MARKETPLACE_{ID}_ID=1
MARKETPLACE_{ID}_EXTERNALID=wb123
MARKETPLACE_{ID}_NAME=Wildberries
MARKETPLACE_{ID}_TOKEN=api_key_here
MARKETPLACE_{ID}_TYPE=WB
```
