# Конфигурация Data Receiver Service

## Структура конфигурации

Конфигурация определена в `config/config.go` и загружается из переменных окружения.

## Основные параметры

### Сервис

```env
SERVICE_NAME=data-receiver  # Название сервиса (по умолчанию)
LOG_LEVEL=-4                 # Уровень логирования (debug=-4, info=0, warn=4)
TIMEOUT=600                  # Таймаут обработки в секундах (по умолчанию 600)
```

### База данных

```env
# Основная БД (writer/reader для разделения нагрузки)
POSTGRES_WRITER_CONN=postgres://user:password@host:5432/dbname?sslmode=disable
POSTGRES_READER_CONN=postgres://user:password@host:5432/dbname?sslmode=disable

# Raw Layer БД (для кэширования сырых данных от API)
POSTGRES_RAW_LAYER_WRITER_CONN=postgres://user:password@host:5432/raw_db?sslmode=disable
POSTGRES_RAW_LAYER_READER_CONN=postgres://user:password@host:5432/raw_db?sslmode=disable
```

### Gateway (HTTP/gRPC)

```env
# HTTP Gateway
GATEWAY_HTTP_HOST=0.0.0.0
GATEWAY_HTTP_PORT=8080

# gRPC сервер
GATEWAY_GRPC_HOST=0.0.0.0
GATEWAY_GRPC_PORT=9090

# Аутентификация
GATEWAY_AUTH_TOKEN=your-secret-token-here

# Swagger документация
GATEWAY_SWAGGER_PATH=docs/swagger
```

### NATS брокер

```env
# Consumer (получение сообщений)
BROKER_CONSUMER_URL=nats://localhost:4222

# Publisher (отправка сообщений)
BROKER_PUBLISHER_URL=nats://localhost:4222
```

### Очередь обработки

```env
QUEUE_WORKERS=1              # Количество воркеров (по умолчанию 1)
QUEUE_MAX_DELIVER=1          # Максимальное количество попыток доставки (по умолчанию 1)
QUEUE_NAK_TIMEOUT_SECONDS=2  # Таймаут перед повторной попыткой в секундах (по умолчанию 2)
QUEUE_ACK_WAIT_SECONDS=60   # Время на обработку сообщения в секундах (по умолчанию 60)
QUEUE_MAX_ACK_PENDING=10000  # Максимальное количество сообщений в ожидании подтверждения (по умолчанию 10000)
```

### Трейсинг

```env
JAEGER_COLLECTOR=http://localhost:14268/api/traces
```

## Конфигурация маркетплейсов

Маркетплейсы настраиваются через переменные окружения с префиксом `MARKETPLACE_{ID}_`:

```env
# Wildberries
MARKETPLACE_1_ID=1
MARKETPLACE_1_EXTERNALID=wb123
MARKETPLACE_1_NAME=Wildberries
MARKETPLACE_1_TOKEN=your-wb-api-key
MARKETPLACE_1_TYPE=WB

# Ozon
MARKETPLACE_2_ID=2
MARKETPLACE_2_EXTERNALID=ozon456
MARKETPLACE_2_NAME=Ozon
MARKETPLACE_2_TOKEN=your-ozon-api-key:your-ozon-client-id
MARKETPLACE_2_TYPE=Ozon

# Yandex Market
MARKETPLACE_3_ID=3
MARKETPLACE_3_EXTERNALID=yandex789
MARKETPLACE_3_NAME=Yandex Market
MARKETPLACE_3_TOKEN=campaignId:businessId:prefix:oauthToken:secret
MARKETPLACE_3_TYPE=Yandex
```

### Формат токенов

Формат токена зависит от маркетплейса:

- **Wildberries**: просто API ключ
- **Ozon**: `api-key:client-id` (через двоеточие)
- **Yandex Market**: `campaignId:businessId:prefix:oauthToken:secret` (5 частей через двоеточие)
- **OdinAss**: зависит от реализации

### Типы маркетплейсов

- `WB` - Wildberries
- `Ozon` - Ozon
- `Yandex` - Yandex Market
- `OdinAss` - OdinAss

## Загрузка конфигурации

Конфигурация загружается при старте приложения в `internal/app/app.go`:

1. Переменные окружения читаются через `sethvargo/go-envconfig`
2. Маркетплейсы парсятся через `FillMarketPlaceMap()`
3. Валидация выполняется через `go-playground/validator`

## Генерация .env файла

Для удобства можно сгенерировать шаблон `.env` файла:

```bash
make gen-envs
```

Это создаст файл `config/local.env` с шаблоном всех переменных окружения.

## Пример полной конфигурации

```env
# Сервис
SERVICE_NAME=data-receiver
LOG_LEVEL=-4
TIMEOUT=600

# БД
POSTGRES_WRITER_CONN=postgres://user:pass@localhost:5432/db?sslmode=disable
POSTGRES_READER_CONN=postgres://user:pass@localhost:5432/db?sslmode=disable
POSTGRES_RAW_LAYER_WRITER_CONN=postgres://user:pass@localhost:5432/raw?sslmode=disable
POSTGRES_RAW_LAYER_READER_CONN=postgres://user:pass@localhost:5432/raw?sslmode=disable

# Gateway
GATEWAY_HTTP_HOST=0.0.0.0
GATEWAY_HTTP_PORT=8080
GATEWAY_GRPC_HOST=0.0.0.0
GATEWAY_GRPC_PORT=9090
GATEWAY_AUTH_TOKEN=secret-token
GATEWAY_SWAGGER_PATH=docs/swagger

# NATS
BROKER_CONSUMER_URL=nats://localhost:4222
BROKER_PUBLISHER_URL=nats://localhost:4222

# Очередь
QUEUE_WORKERS=1
QUEUE_MAX_DELIVER=1
QUEUE_NAK_TIMEOUT_SECONDS=2
QUEUE_ACK_WAIT_SECONDS=60
QUEUE_MAX_ACK_PENDING=10000

# Jaeger
JAEGER_COLLECTOR=http://localhost:14268/api/traces

# Маркетплейсы
MARKETPLACE_1_ID=1
MARKETPLACE_1_EXTERNALID=wb123
MARKETPLACE_1_NAME=Wildberries
MARKETPLACE_1_TOKEN=wb-api-key
MARKETPLACE_1_TYPE=WB
```

## Валидация

Конфигурация валидируется при загрузке:
- Обязательные поля: `BROKER_CONSUMER_URL`, `BROKER_PUBLISHER_URL`
- Проверка формата подключений к БД
- Проверка формата токенов маркетплейсов
