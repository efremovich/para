# Сущности данных

Проект содержит 32 файла с доменными сущностями в `internal/entity/`. Все сущности представляют единую модель данных для работы с различными маркетплейсами.

## Основные сущности

### Card (card.go)
Карточка товара - основная сущность для представления товара.

**Поля:**
- `ExternalID` - внешний ID товара (SKU)
- `VendorID` - ID производителя
- `VendorCode` - код производителя
- `Title` - название товара
- `Description` - описание
- `Brand` - бренд
- `Categories` - категории товара
- `Sizes` - размеры товара
- `Barcodes` - штрихкоды
- `Characteristics` - характеристики товара
- `Dimension` - габариты (ширина, высота, длина, вес)
- `MediaFile` - медиафайлы (фото, видео)
- `UpdatedAt` - дата обновления

### Order (order.go)
Заказ - информация о заказе товара.

**Поля:**
- `ExternalID` - внешний ID заказа
- `Price` - цена
- `PriceWithoutDiscount` - цена без скидки
- `PriceFinal` - итоговая цена
- `Type` - тип заказа
- `Direction` - направление (статус)
- `Sale` - размер скидки
- `IsCancel` - отменен ли заказ
- `Quantity` - количество товара
- `CreatedAt` / `UpdatedAt` - даты создания/обновления
- `Status` - статус заказа
- `Region` - регион доставки
- `Warehouse` - склад
- `Card` - карточка товара
- `PriceSize` - информация о цене
- `Barcode` - штрихкод
- `Size` - размер товара

### Sale (sale.go)
Продажа - информация о совершенной продаже.

**Поля:**
- `ExternalID` - внешний ID продажи
- `Price` - цена продажи
- `PriceWithoutDiscount` - цена без скидки
- `PriceFinal` - итоговая цена
- `Type` - тип продажи
- `Quantity` - количество
- `CreatedAt` / `UpdatedAt` - даты
- `Status` - статус
- `Region` - регион
- `Warehouse` - склад
- `Card` - карточка товара
- `PriceSize` - информация о цене
- `Barcode` - штрихкод
- `Size` - размер товара

### Stock (stock.go)
Остаток товара на складе.

**Поля:**
- `Quantity` - количество товара
- `CreatedAt` / `UpdatedAt` - даты

### StockMeta (stock_report_meta.go)
Метаданные остатков товара.

**Поля:**
- `Stock` - остаток товара
- `Seller2Card` - связь продавца с карточкой
- `Card` - карточка товара
- `Warehouse` - склад

### Warehouse (warehouse.go)
Склад - информация о складе маркетплейса.

**Поля:**
- `ExternalID` - внешний ID склада
- `Title` - название склада
- `Address` - адрес
- `Sity` - город
- `Longitude` / `Latitude` - координаты
- `TypeID` - тип склада (1-FULFILLMENT, 2-DROPSHIP, 3-CROSSDOCK)
- `TypeName` - название типа
- `CargoTypeID` - тип груза
- `SellerID` - ID продавца

### Promotion (promotion.go)
Акция/промо-кампания.

**Поля:**
- `ExternalID` - внешний ID акции
- `Title` - название
- `StartDate` / `EndDate` - даты начала/окончания
- `Discount` - размер скидки
- И другие поля статистики

### MediaCampaign (media_compaing.go)
Медиа-кампания - рекламная кампания.

**Поля:**
- `ExternalID` - внешний ID кампании
- `Title` - название
- `Status` - статус
- `Budget` - бюджет
- И другие поля

### SaleReport (salereport.go)
Отчет о продажах.

**Поля:**
- Различные метрики продаж
- Даты отчетного периода
- Статистика по товарам

### ReturnsReport (returns_report.go)
Отчет о возвратах товаров.

### DeductionsReport (deductions_report.go)
Отчет об удержаниях (штрафы, комиссии).

**Типы удержаний:**
- Antifraud (мошенничество)
- IncorrectAttachments (неправильные вложения)
- StorageCoefficient (коэффициент хранения)
- GoodsLabeling (маркировка товаров)
- CharacteristicsChange (изменение характеристик)

### SalesFunnel (sales_funnel.go)
Воронка продаж - аналитика по продажам.

### PaidStorage (paid_storage.go)
Платное хранилище - отчеты о платном хранении товаров.

### PaidAcceptance (paid_acceptance.go)
Платная приемка - отчеты о платной приемке товаров.

## Особенности модели данных

1. **Единая модель** - все маркетплейсы используют одни и те же сущности
2. **ExternalID** - для связи с внешними системами
3. **Вложенные структуры** - Region содержит District и Country
4. **Связи через указатели** - многие поля являются указателями для опциональности
5. **Временные метки** - CreatedAt/UpdatedAt для отслеживания изменений
