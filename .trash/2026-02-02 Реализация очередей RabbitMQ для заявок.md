# 2026-02-02 Реализация очередей RabbitMQ для заявок

## Выполнено

Реализована система очередей RabbitMQ для заявок на смену лимита и блокировку карт.

### Основные компоненты

1. **Структуры сообщений** (`internal/entity/message.go`):
   - `RequestMessage` - для отправки заявок в downstream очередь
   - `RequestAckMessage` - для получения подтверждений из upstream очереди
   - `CardStatusUpdate` - для обновления статусов карт

2. **RabbitMQ Producer** (`internal/service/rabbitmq/producer.go`):
   - Отправка заявок типов EDIT и LOCK в downstream очередь
   - Routing keys: `requests.edit`, `requests.lock`
   - Автоматическое переподключение при ошибках

3. **RabbitMQ Consumer** (`internal/service/rabbitmq/consumer.go`):
   - Получение подтверждений из upstream очереди
   - Routing key: `requests.acks`
   - Обработка сообщений с логированием и метриками

4. **Обработчик сообщений** (`internal/service/rabbitmq/handler.go`):
   - Парсинг JSON сообщений от 1С
   - Обновление статусов заявок (COMPLETED/CANCELLED)
   - Обновление статусов карт
   - Обновление лимитов для заявок типа EDIT
   - Idempotency проверка для предотвращения дублирования

5. **Расширение usecase**:
   - `CreateRequestAndPublish` - создание заявки и отправка в очередь
   - `GetRequestStatusesByCode` - получение статусов по коду
   - `GetCardStatusesByCode` - получение статусов карт по коду
   - `GetCardByID`, `UpdateCard` - работа с картами
   - `GetRequestTypeByID`, `GetRequestTypeByCode` - работа с типами заявок

6. **Обновление контроллера** (`internal/controller/requests.go`):
   - Автоматическая отправка заявок типов EDIT и LOCK в очередь
   - Проверка типа заявки перед отправкой

7. **Интеграция в приложение** (`internal/app/app.go`):
   - Создание RabbitMQ сервиса при старте
   - Запуск consumer в отдельной горутине
   - Graceful shutdown для закрытия соединений

### Конфигурация

- Добавлены константы routing keys в `config/config.go`:
  - `RoutingKeyRequestsEdit`
  - `RoutingKeyRequestsLock`
  - `RoutingKeyRequestsAcks`

### Обработка ошибок

- Логирование всех операций
- Автоматическое переподключение при сбоях
- Idempotency проверка для предотвращения дублирования
- Обработка некорректных сообщений
- Retry механизм для producer

### Зависимости

- Добавлена библиотека `github.com/rabbitmq/amqp091-go` для работы с RabbitMQ
