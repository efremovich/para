# Реализация механизма работы с очередями RabbitMQ в 1С

## Дата: 2026-02-02

## Выполнено

Реализован механизм работы с очередями RabbitMQ в клиенте 1С для обработки заявок на изменение лимитов и блокировку карт.

### Созданные файлы:

1. **ОбщиеМодули/FuelAppAPIRabbitMQ.bsl**
   - Подключение к RabbitMQ через HTTP API Management Plugin
   - Получение сообщений из очередей
   - Отправка сообщений в exchange
   - Управление настройками RabbitMQ

2. **ОбщиеМодули/FuelAppAPIЗаявки.bsl**
   - Обработка заявок типа EDIT (изменение лимита)
   - Обработка заявок типа LOCK (блокировка карты)
   - Формирование и отправка подтверждений
   - Механизм idempotency для защиты от повторной обработки

3. **Обработки/FuelAppAPIОбработкаЗаявок.bsl**
   - Периодическая обработка заявок из очередей
   - Непрерывная обработка с настраиваемым интервалом
   - Тестовые функции для проверки работы

4. **РегистрыСведений/FuelAppAPIЗаявки.md**
   - Описание регистра для отслеживания обработанных заявок

5. **README_QUEUES.md**
   - Документация по использованию механизма очередей

### Расширения:

- Обновлен **FuelAppAPIConfig.md** - добавлены настройки RabbitMQ
- Обновлен **СТРУКТУРА_ПРОЕКТА.md** - добавлена информация о новых модулях
- Обновлен **FuelAppAPITest.bsl** - добавлены тесты для очередей

### Архитектура:

- **Downstream очереди**: `downstreamExchange.requests.edit` и `downstreamExchange.requests.lock`
- **Upstream очередь**: `upstreamExchange.requests.acks`
- Используется HTTP API RabbitMQ Management Plugin (порт 15672)
- Периодический опрос очередей с настраиваемым интервалом

### Особенности:

- Поддержка idempotency через регистр обработанных заявок
- Обработка ошибок с логированием
- Готовые заглушки для интеграции с бизнес-логикой 1С
- Тестовые функции для проверки работы
