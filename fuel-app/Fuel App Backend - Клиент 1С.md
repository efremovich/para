# Fuel App Backend - Клиент 1С

## Обзор

Реализован клиент 1С для интеграции с fuel-app-backend API. Клиент построен по модульной архитектуре с разделением на слои и включает все необходимые компоненты для работы с API.

## Структура решения

### Регистры сведений

1. **FuelAppAPIConfig** - хранение конфигурационных настроек подключения
   - Измерения: Ключ (Строка)
   - Ресурсы: Значение (Строка)
   - Ключи: BaseURL, Timeout, AutoRefreshToken

2. **FuelAppAPITokens** - хранение access и refresh токенов
   - Измерения: Пользователь (Строка)
   - Ресурсы: AccessToken, RefreshToken, ExpiresAt

### Общие модули

1. **FuelAppAPIУтилиты** - функции преобразования JSON и работы с датами
   - `ПреобразоватьВJSON()` - преобразование структур 1С в JSON
   - `ПреобразоватьИзJSON()` - парсинг JSON в структуры 1С
   - `ПреобразоватьДатуВTimestamp()` - преобразование даты 1С в RFC3339
   - `ПреобразоватьTimestampВДату()` - обратное преобразование
   - `СформироватьЗаголовкиАвторизации()` - формирование заголовка Authorization

2. **FuelAppAPIHTTP** - выполнение HTTP запросов к API
   - `ВыполнитьHTTPЗапрос()` - выполнение GET/POST/PUT/DELETE запросов
   - `ПолучитьJSONИзОтвета()` - парсинг JSON из ответа
   - `ОбработатьОшибкуAPI()` - обработка ошибок API

3. **FuelAppAPIАутентификация** - управление авторизацией и токенами
   - `Авторизоваться()` - авторизация пользователя
   - `Зарегистрироваться()` - регистрация нового пользователя
   - `ПолучитьПрофиль()` - получение профиля пользователя
   - `ОбновитьТокен()` - обновление access token
   - `ВыйтиИзСистемы()` - выход из системы
   - `ПроверитьИОбновитьТокен()` - автоматическая проверка и обновление

4. **FuelAppAPIКлиент** - основной модуль клиента
   - `УстановитьНастройки()` - настройка подключения
   - `ВыполнитьЗапрос()` - выполнение API запроса с автоматической подстановкой токена

5. **FuelAppAPIПользователи** - сервис для работы с пользователями
   - `ПолучитьСтатусыПользователей()`
   - `ПолучитьУстройстваПользователя()`
   - `ПолучитьУстройство()`
   - `СоздатьУстройство()`
   - `ОбновитьУстройство()`
   - `УдалитьУстройство()`

6. **FuelAppAPIКарты** - сервис для работы с топливными картами
   - `ПолучитьКартыПользователя()`
   - `ПолучитьКартыПоФильтрам()`
   - `ДобавитьКартуПользователю()`
   - `УдалитьКартуУПользователя()`

7. **FuelAppAPIКомпании** - сервис для работы с компаниями
   - `ПолучитьКомпанию()`
   - `ПолучитьКомпаниюПоИНН()`
   - `ПолучитьСписокКомпаний()`
   - `СоздатьКомпанию()`
   - `ОбновитьКомпанию()`
   - `УдалитьКомпанию()`

8. **FuelAppAPIТранзакции** - сервис для работы с транзакциями
   - `ПолучитьТранзакции()`
   - `ПолучитьТранзакцию()`

### Обработки

1. **FuelAppAPITest** - тестовая обработка для проверки работы клиента
   - `ТестАвторизации()`
   - `ТестПользователи()`
   - `ТестКарты()`
   - `ТестКомпании()`
   - `ТестТранзакции()`
   - `ПолныйТест()`

## Быстрый старт

### 1. Настройка подключения

```bsl
FuelAppAPIКлиент.УстановитьНастройки("http://localhost:8080", 30, Истина);
```

### 2. Авторизация

```bsl
Успех = FuelAppAPIАутентификация.Авторизоваться("user@example.com", "password");
```

### 3. Получение данных

```bsl
// Получение карт пользователя
Карты = FuelAppAPIКарты.ПолучитьКартыПользователя("user-id");

// Получение транзакций
Параметры = Новый Структура;
Параметры.Вставить("date_from", НачалоДня(ТекущаяДата() - 30));
Параметры.Вставить("date_to", КонецДня(ТекущаяДата()));
Параметры.Вставить("page_size", 10);
Параметры.Вставить("page_number", 1);
Транзакции = FuelAppAPIТранзакции.ПолучитьТранзакции(Параметры);
```

## Особенности реализации

### Автоматическое обновление токенов

Клиент автоматически обновляет access token при его истечении, если включено автоматическое обновление (по умолчанию включено).

### Обработка ошибок

Все ошибки API обрабатываются и преобразуются в исключения 1С с понятными сообщениями.

### Работа с датами

Даты автоматически преобразуются между форматом 1С и RFC3339 timestamp для protobuf.

### HTTP запросы

- GET запросы: параметры передаются в URL как query string
- POST/PUT/DELETE запросы: параметры передаются в теле запроса как JSON
- Автоматическая обработка ошибок авторизации (401) с повторной попыткой после обновления токена
