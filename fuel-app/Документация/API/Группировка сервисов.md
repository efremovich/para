# Группировка сервисов API

## Обзор

Всего в проекте реализовано **23 gRPC сервиса**, которые автоматически экспонируются через HTTP REST API через grpc-gateway.

## Группировка по функциональности

### 1. Аутентификация и пользователи
- **AuthService** - Аутентификация, регистрация, управление токенами
- **UserService** - Управление пользователями, статусами, устройствами

### 2. Компании и организации
- **CompanyService** - Управление компаниями
- **OrganizationService** - Управление организациями
- **OfficeService** - Управление офисами
- **DepartmentService** - Управление отделами и подразделениями

### 3. Карты и транзакции
- **CardService** - Управление топливными картами
- **TransactionService** - Управление транзакциями
- **LimitService** - Управление лимитами
- **EmitentService** - Управление эмитентами карт

### 4. Контракты и платежи
- **ContractService** - Управление контрактами и типами контрактов
- **PaymentService** - Управление платежами

### 5. Услуги и точки обслуживания
- **ServiceService** - Управление услугами и группами услуг
- **POSService** - Управление точками обслуживания (POS)

### 6. Документы и заявки
- **DocumentService** - Управление документами
- **RegulatoryDocumentsService** - Управление нормативными документами
- **RequestService** - Управление заявками

### 7. Коммуникации
- **ContactService** - Управление контактами
- **NotificationService** - Управление уведомлениями
- **NewsService** - Управление новостями

### 8. Контент и настройки
- **AdvertisementService** - Управление рекламными баннерами
- **AppInfoService** - Управление информацией о версиях приложения

## Swagger документация

Swagger документация доступна по адресу: `/swagger/`

Для группировки в Swagger UI можно использовать:
1. Префиксы в названиях тегов (например, "1. Аутентификация", "3. Компании")
2. Расширения x-tagGroups в swagger файле
3. Структурированные названия тегов с разделителями
