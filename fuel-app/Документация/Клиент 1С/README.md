e# Клиент 1С для обмена с fuel-app-backend API

Клиент для интеграции конфигурации 1С с fuel-app-backend API.

## Структура решения

### Регистры сведений

1. **FuelAppAPIConfig** - хранение конфигурационных настроек подключения
2. **FuelAppAPITokens** - хранение access и refresh токенов

### Общие модули

1. **FuelAppAPIУтилиты** - функции преобразования JSON и работы с датами
2. **FuelAppAPIHTTP** - выполнение HTTP запросов к API
3. **FuelAppAPIАутентификация** - управление авторизацией и токенами
4. **FuelAppAPIКлиент** - основной модуль клиента с управлением сессией
5. **FuelAppAPIПользователи** - сервис для работы с пользователями
6. **FuelAppAPIКарты** - сервис для работы с топливными картами
7. **FuelAppAPIКомпании** - сервис для работы с компаниями
8. **FuelAppAPIТранзакции** - сервис для работы с транзакциями

### Обработки

1. **FuelAppAPITest** - тестовая обработка для проверки работы клиента

## Установка

1. Импортируйте регистры сведений `FuelAppAPIConfig` и `FuelAppAPITokens` в конфигурацию 1С
2. Импортируйте все общие модули в конфигурацию 1С
3. Импортируйте обработку `FuelAppAPITest` (опционально, для тестирования)

## Быстрый старт

### 1. Настройка подключения

```bsl
// Установка базового URL и таймаута
FuelAppAPIКлиент.УстановитьНастройки("http://localhost:8080", 30, Истина);
```

### 2. Авторизация

```bsl
// Авторизация по email или телефону
Успех = FuelAppAPIАутентификация.Авторизоваться("user@example.com", "password");

Если Успех Тогда
    Сообщить("Авторизация успешна!");
КонецЕсли;
```

### 3. Получение данных

```bsl
// Получение карт пользователя
Карты = FuelAppAPIКарты.ПолучитьКартыПользователя("user-id");

// Получение транзакций с фильтрацией
Параметры = Новый Структура;
Параметры.Вставить("date_from", НачалоДня(ТекущаяДата() - 30));
Параметры.Вставить("date_to", КонецДня(ТекущаяДата()));
Параметры.Вставить("page_size", 10);
Параметры.Вставить("page_number", 1);
Транзакции = FuelAppAPIТранзакции.ПолучитьТранзакции(Параметры);
```

### 4. Создание данных

```bsl
// Создание компании
ДанныеКомпании = Новый Структура;
ДанныеКомпании.Вставить("legal_name", "ООО Пример");
ДанныеКомпании.Вставить("inn", "1234567890");
Результат = FuelAppAPIКомпании.СоздатьКомпанию(ДанныеКомпании);
```

## Примеры использования

### Авторизация и получение профиля

```bsl
// Настройка
FuelAppAPIКлиент.УстановитьНастройки("http://localhost:8080", 30, Истина);

// Авторизация
FuelAppAPIАутентификация.Авторизоваться("user@example.com", "password");

// Получение профиля
Профиль = FuelAppAPIАутентификация.ПолучитьПрофиль();
Сообщить("Пользователь: " + Профиль.user.f + " " + Профиль.user.i);
Сообщить("Компания: " + Профиль.company.legal_name);
```

### Работа с картами

```bsl
// Получение карт пользователя
Карты = FuelAppAPIКарты.ПолучитьКартыПользователя("user-id");

Для Каждого Карта Из Карты Цикл
    Сообщить("Карта: " + Карта.number + ", статус: " + Карта.status_name);
КонецЦикла;

// Добавление карты пользователю
Результат = FuelAppAPIКарты.ДобавитьКартуПользователю("user-id", "card-id");
```

### Работа с компаниями

```bsl
// Получение компании по ИНН
Компания = FuelAppAPIКомпании.ПолучитьКомпаниюПоИНН("1234567890");

// Получение списка компаний с пагинацией
Параметры = Новый Структура;
Параметры.Вставить("page_size", 20);
Параметры.Вставить("page_number", 1);
Параметры.Вставить("search", "ООО");
Результат = FuelAppAPIКомпании.ПолучитьСписокКомпаний(Параметры);
```

### Работа с транзакциями

```bsl
// Получение транзакций за период
Параметры = Новый Структура;
Параметры.Вставить("date_from", НачалоДня(ТекущаяДата() - 7));
Параметры.Вставить("date_to", КонецДня(ТекущаяДата()));
Параметры.Вставить("card_id", "card-id");
Параметры.Вставить("page_size", 50);
Параметры.Вставить("page_number", 1);

Результат = FuelAppAPIТранзакции.ПолучитьТранзакции(Параметры);

Для Каждого Транзакция Из Результат.transactions Цикл
    ДатаТранзакции = FuelAppAPIУтилиты.ПреобразоватьTimestampВДату(Транзакция.date);
    Сообщить(Формат(ДатаТранзакции, "ДФ=dd.MM.yyyy HH:mm:ss") + 
        " - " + Транзакция.summ + " руб., карта: " + Транзакция.card_number);
КонецЦикла;
```

## Особенности

### Автоматическое обновление токенов

Клиент автоматически обновляет access token при его истечении, если включено автоматическое обновление (по умолчанию включено).

### Обработка ошибок

Все ошибки API обрабатываются и преобразуются в исключения 1С с понятными сообщениями.

### Работа с датами

Даты автоматически преобразуются между форматом 1С и RFC3339 timestamp для protobuf.

## Тестирование

Используйте обработку `FuelAppAPITest` для тестирования всех функций клиента:

```bsl
// Запуск полного теста
FuelAppAPITest.ПолныйТест();

// Или отдельные тесты
FuelAppAPITest.ТестАвторизации();
FuelAppAPITest.ТестКарты();
FuelAppAPITest.ТестКомпании();
FuelAppAPITest.ТестТранзакции();
```

## Требования

- 1С:Предприятие 8.3.20 или выше (для поддержки JSON)
- Доступ к fuel-app-backend API
