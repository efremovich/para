# CI/CD

## Обзор

Проект использует GitLab CI/CD для автоматизации сборки и деплоя.

## Стадии пайплайна

1. **build** - Сборка Docker образа приложения
2. **build-migrations** - Сборка Docker образа для миграций
3. **migrate** - Выполнение миграций базы данных
4. **deploy** - Деплой приложения

## Registry

Docker образы хранятся в Harbor registry (`harbor.autocard-yug.ru`).

## Конфигурация

Конфигурация CI/CD находится в файле `.gitlab-ci.yml` в корне проекта.
