# Система документов

## Обзор

Система документов включает одну таблицу:
- `documents` - хранит информацию о документах, связанных с компаниями

## Таблица documents

Таблица хранит информацию о документах, связанных с компаниями.

**Поля:**
- `id` - UUID, первичный ключ
- `company_id` - UUID, внешний ключ на таблицу companies
- `title` - текст, название документа
- `document_date` - дата документа
- `file_path` - текст, ссылка на файл документа (PDF)
- `file_name` - текст, имя файла документа
- `file_size` - bigint, размер файла в байтах
- `description` - текст, описание документа
- `document_type` - текст, тип документа (например, 'contract', 'report', 'invoice' и т.д.)
- `created_at` - дата создания
- `updated_at` - дата обновления
- `deleted_at` - дата удаления (для мягкого удаления)

## Работа системы

### 1. Создание документа

- Документ создается и привязывается к конкретной компании
- Документ должен иметь название и путь к файлу
- Может иметь дату, описание, тип и другие метаданные

## Примеры использования

### Создание документа:

```sql
INSERT INTO documents (company_id, title, document_date, file_path, file_name, file_size, description, document_type)
VALUES ('[ID компании]', 'Договор поставки топлива', '2023-01-15', '/uploads/documents/contract_001.pdf', 'contract_001.pdf', 2048576, 'Договор на поставку дизельного топлива', 'contract');
```

### Получение всех документов компании:

```sql
SELECT id, title, document_date, file_name, file_size, description, document_type, created_at
FROM documents
WHERE company_id = '[ID компании]'
  AND deleted_at IS NULL
ORDER BY document_date DESC, created_at DESC;
```

### Получение документа по типу:

```sql
SELECT id, title, document_date, file_path, file_name
FROM documents
WHERE company_id = '[ID компании]'
  AND document_type = 'contract'
  AND deleted_at IS NULL;
```

### Получение информации о документе:

```sql
SELECT title, document_date, file_path, file_name, file_size, description
FROM documents
WHERE id = '[ID документа]'
  AND deleted_at IS NULL;
```

## Особенности

- Каждый документ обязательно связан с компанией
- Используется мягкое удаление для сохранения целостности исторических данных
- Хранение размера файла позволяет отслеживать объем хранимых данных
- Поддержка типов документов позволяет фильтровать и классифицировать документы
- Индекс по дате документа позволяет эффективно сортировать и фильтровать
- Поле файла может хранить относительный путь или URL для доступа к файлу
- Поддержка описания позволяет добавлять дополнительную информацию о документе
