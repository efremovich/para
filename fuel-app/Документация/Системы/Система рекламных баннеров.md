# Система рекламных баннеров

## Обзор

Система рекламных баннеров включает таблицу `advertisements`, которая хранит информацию о баннерах, отображаемых в приложении.

## Таблица advertisements

Таблица хранит рекламные баннеры, которые могут отображаться в приложении.

**Поля:**
- `id` - UUID, первичный ключ
- `title` - текст, заголовок рекламы
- `description` - текст, описание рекламы
- `image_url` - текст, ссылка на изображение баннера
- `link_url` - текст, ссылка, на которую ведет баннер
- `is_active` - boolean, активна ли реклама (по умолчанию TRUE)
- `priority` - integer, приоритет отображения (чем больше, тем выше)
- `target_audience` - массив текста, целевая аудитория (роли пользователей)
- `start_date` - дата начала показа рекламы
- `end_date` - дата окончания показа рекламы
- `created_at` - дата создания
- `updated_at` - дата обновления
- `deleted_at` - дата удаления (для мягкого удаления)

## Работа системы

Рекламные баннеры:
- Создаются администратором с указанием заголовка, описания, изображения и целевой ссылки
- Могут быть нацелены на конкретные роли пользователей через поле `target_audience`
- Имеют приоритет отображения и даты начала/окончания показа
- Могут быть временно отключены без удаления (через поле `is_active`)

## Примеры запросов

### Получение активных рекламных баннеров для пользователя:

```sql
SELECT id, title, description, image_url, link_url
FROM advertisements
WHERE is_active = TRUE
  AND (target_audience = '{}' OR '[роль_пользователя]' = ANY(target_audience))
  AND (start_date IS NULL OR start_date <= now())
  AND (end_date IS NULL OR end_date >= now())
ORDER BY priority DESC;
```

### Создание нового рекламного баннера:

```sql
INSERT INTO advertisements (title, description, image_url, link_url, priority, target_audience, start_date, end_date)
VALUES ('Новый топливо-сертификат', 'Получите специальные условия по топливным картам', 'https://example.com/banner1.jpg', 'https://example.com/cert', 10, '{client,driver}', '2023-01-01', '2023-12-31');
```

### Отключение рекламного баннера:

```sql
UPDATE advertisements
SET is_active = FALSE, updated_at = now()
WHERE id = '[ID баннера]';
```

## Особенности

- Рекламные баннеры могут быть настроены для показа определенным ролям пользователей с возможностью указания приоритета и дат начала/окончания показа
- Используется мягкое удаление, чтобы сохранить историю рекламных кампаний
- Поддерживается таргетирование по ролям пользователей
- Возможность задания времени показа рекламы
- Поддержка приоритетов для управления порядком отображения
