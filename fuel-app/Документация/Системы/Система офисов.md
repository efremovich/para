# Система офисов и организаций

## Обзор

Система включает две таблицы:
- `organizations` - хранит информацию об организациях, с которыми клиенты заключают договоры
- `offices` - хранит информацию о офисах, связанных с организациями

## Таблица organizations

Таблица хранит информацию об организациях, с которыми клиенты заключают договоры.

**Поля:**
- `id` - UUID, первичный ключ
- `company_id` - UUID, внешний ключ на таблицу companies
- `name` - текст, название организации
- `legal_name` - текст, юридическое название организации
- `inn` - varchar(12), ИНН организации
- `kpp` - varchar(9), КПП организации
- `ogrn` - varchar(15), ОГРН организации
- `legal_address` - текст, юридический адрес
- `actual_address` - текст, фактический адрес
- `phone` - varchar(20), телефон
- `email` - varchar(255), email
- `director_name` - текст, ФИО руководителя
- `accountant_name` - текст, ФИО главного бухгалтера
- `created_at` - дата создания
- `updated_at` - дата обновления
- `deleted_at` - дата удаления (для мягкого удаления)

## Таблица offices

Таблица хранит информацию о офисах, связанных с организациями.

**Поля:**
- `id` - UUID, первичный ключ
- `company_id` - UUID, внешний ключ на таблицу companies
- `organization_id` - UUID, внешний ключ на таблицу organizations
- `name` - текст, название офиса
- `address` - текст, адрес офиса
- `phone` - текст, телефон офиса
- `email` - текст, email офиса
- `coordinates` - точка (x, y), координаты офиса для карты
- `is_main` - boolean, является ли офис головным (по умолчанию FALSE)
- `created_at` - дата создания
- `updated_at` - дата обновления
- `deleted_at` - дата удаления (для мягкого удаления)

## Работа системы

### 1. Создание организации

- Организация создается и привязывается к конкретной компании
- Организация должна иметь название
- Может иметь юридические реквизиты (ИНН, КПП, ОГРН)
- Может иметь юридический и фактический адреса
- Может содержать информацию о руководителе и главном бухгалтере

### 2. Создание офиса

- Офис создается и привязывается к конкретной организации (через organization_id)
- Также сохраняется связь с компанией (через company_id)
- Офис должен иметь название и адрес
- Может иметь контактную информацию (телефон, email)
- Можно указать координаты для отображения на карте
- Можно отметить офис как головной

## Примеры использования

### Создание организации:

```sql
INSERT INTO organizations (company_id, name, legal_name, inn, kpp, legal_address, actual_address, phone, email, director_name)
VALUES ('[ID компании]', 'ООО "Ромашка"', 'Общество с ограниченной ответственностью "Ромашка"', '123456789012', '123456789', 'г. Москва, ул. Примерная, д. 1', 'г. Москва, ул. Фактическая, д. 2', '+7 (495) 123-45-67', 'info@romashka.ru', 'Иванов Иван Иванович');
```

### Создание офиса:

```sql
INSERT INTO offices (company_id, organization_id, name, address, phone, email, coordinates, is_main)
VALUES ('[ID компании]', '[ID организации]', 'Головной офис', 'г. Москва, ул. Тверская, д. 1', '+7 (495) 123-45-67', 'office@example.com', point(37.6184, 55.7512), TRUE);
```

### Создание дополнительного офиса:

```sql
INSERT INTO offices (company_id, organization_id, name, address, phone, coordinates)
VALUES ('[ID компании]', '[ID организации]', 'Филиал в Санкт-Петербурге', 'г. Санкт-Петербург, Невский проспект, д. 10', '+7 (812) 123-45-67', point(30.3158, 59.9343));
```

### Получение всех офисов организации:

```sql
SELECT o.id, o.name, o.address, o.phone, o.email, o.coordinates, o.is_main
FROM offices o
JOIN organizations org ON o.organization_id = org.id
WHERE org.id = '[ID организации]'
  AND o.deleted_at IS NULL
ORDER BY o.is_main DESC, o.name ASC;
```

### Получение всех офисов компании:

```sql
SELECT o.id, o.name, o.address, o.phone, o.email, o.coordinates, o.is_main
FROM offices o
WHERE o.company_id = '[ID компании]'
  AND o.deleted_at IS NULL
ORDER BY o.is_main DESC, o.name ASC;
```

### Получение головного офиса компании:

```sql
SELECT o.id, o.name, o.address, o.phone, o.email, o.coordinates
FROM offices o
WHERE o.company_id = '[ID компании]'
  AND o.is_main = TRUE
  AND o.deleted_at IS NULL;
```

### Получение офисов по координатам (в радиусе 10 км от заданной точки):

```sql
SELECT o.id, o.name, o.address, o.phone
FROM offices o
WHERE o.coordinates <-> point(37.6184, 55.7512) < 10000  -- 10000 метров = 10 км
  AND o.deleted_at IS NULL;
```

### Обновление информации об офисе:

```sql
UPDATE offices
SET phone = '+7 (495) 987-65-43', email = 'new-email@company.com', updated_at = now()
WHERE id = '[ID офиса]';
```

## Особенности

- Каждая организация обязательно связана с компанией
- Каждый офис связан как с организацией (organization_id), так и с компанией (company_id)
- Используется мягкое удаление для сохранения целостности исторических данных
- Поле coordinates позволяет хранить координаты офиса для отображения на карте
- Индекс по координатам позволяет эффективно искать офисы в заданном радиусе
- Поддержка отметки головного офиса позволяет легко идентифицировать главный офис
- Индекс по is_main позволяет быстро находить головные офисы
- Поддержка юридических реквизитов организаций (ИНН, КПП, ОГРН)
- Хранение контактной информации (телефон, email) как для организаций, так и для офисов
- Возможность хранения информации о руководителе и главном бухгалтере организации
