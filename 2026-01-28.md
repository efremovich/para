### Особенности реализации

- Все три метода используют асинхронную генерацию отчетов через API Yandex Market
- Единый подход: создание задачи → проверка статуса → скачивание отчета
- Обработка ZIP архивов с парсингом JSON файлов
- Адаптивные интервалы проверки статуса на основе `estimatedGenerationTime`
- Поддержка raw layer для кэширования данных
- Обработка всех статусов и подстатусов отчетов

### Технические детали

- Использованы существующие методы: `checkReportStatus()`, `makeRequest()`, `parseOfferID()`
- Константы: `maxStatusCheckAttempts = 30`, `statusCheckInterval = 5 * time.Second`
- Лимиты API: 100 запросов в час на генерацию, 100 запросов в минуту на проверку статуса
- Все методы компилируются и проходят проверку golangci-lint
