	Необходимо создать заявку в jira пример [DevOps](https://track.astral.ru/soft/browse/DEVOPS-2053) для создания баз данных.

Замер времени прохождение документа за промежуток времени.
```
WITH selectedDocs AS (
    SELECT d.id 
    FROM docs d
    WHERE d.created::timestamptz > '2026-04-14 11:35:00'
      AND d.created::timestamptz < '2026-04-14 11:36:00'
)
SELECT 
    l.inbox,
    COUNT(*) AS cnt,
    AVG(l.processed::timestamptz - l.created::timestamptz) AS avg_time,
    percentile_cont(0.5)  WITHIN GROUP (ORDER BY l.processed::timestamptz - l.created::timestamptz) AS p50,
    percentile_cont(0.95) WITHIN GROUP (ORDER BY l.processed::timestamptz - l.created::timestamptz) AS p95
FROM ls2docs ld
JOIN ls l ON l.id = ld.ls
WHERE ld.doc IN (SELECT id FROM selectedDocs)
GROUP BY l.inbox;
```

Расчет ведется от даты создания входящей ЛС под дату окончания процессинга у исходящей ЛС.
