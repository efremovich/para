# Шаблоны Templater

Эта папка содержит шаблоны для использования с плагином Templater в Obsidian.

## Доступные шаблоны

### Ежедневная заметка.md
Полнофункциональный шаблон для ежедневных заметок с:
- Автоматической датой и навигацией
- Календарем недели
- Разделами для задач, заметок и проектов
- Интеграцией с главной доской задач
- Статистикой дня

### Ежедневная заметка (простая).md
Упрощенная версия для быстрого создания заметок.

### Заметка проекта.md
Шаблон для создания заметок по проектам с разделами для целей, задач и ссылок.

### Настройка Daily Notes.md
Инструкция по настройке Daily Notes плагина для работы с шаблонами.

## Использование

### Настройка Daily Notes с Templater

1. Откройте настройки Obsidian → Daily Notes
2. Установите формат даты: `YYYY-MM-DD`
3. Включите опцию "Use Templater template"
4. Выберите шаблон: `template/Ежедневная заметка.md`

### Ручное создание заметки

1. Нажмите `Ctrl+P` (или `Cmd+P` на Mac)
2. Введите "Templater: Create new note from template"
3. Выберите нужный шаблон

### Горячие клавиши

Можно настроить горячую клавишу для быстрого создания заметки:
1. Настройки → Горячие клавиши
2. Найдите "Templater: Create new note from template"
3. Назначьте удобную комбинацию (например, `Ctrl+Shift+D`)

## Функции Templater в шаблонах

### Даты
- `<% tp.date.now("YYYY-MM-DD") %>` - текущая дата
- `<% tp.date.yesterday("YYYY-MM-DD") %>` - вчера
- `<% tp.date.tomorrow("YYYY-MM-DD") %>` - завтра
- `<% tp.date.now("YYYY-MM-DD", -7) %>` - неделю назад
- `<% tp.date.now("YYYY-MM-DD HH:mm") %>` - дата и время

### Навигация
Шаблон автоматически создает ссылки на предыдущий и следующий день.

### Календарь недели
Автоматически генерируется календарь текущей недели с выделением сегодняшнего дня.
