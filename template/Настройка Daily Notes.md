# Настройка Daily Notes с Templater

## Шаг 1: Настройка Daily Notes плагина

1. Откройте **Настройки** → **Daily Notes**
2. Установите следующие параметры:
   - **Формат даты:** `YYYY-MM-DD`
   - **Папка для заметок:** (оставьте пустым для корневой папки)
   - **Шаблон:** `template/Ежедневная заметка.md`

## Шаг 2: Настройка Templater (опционально)

Если хотите использовать Templater автоматически при создании Daily Notes:

1. Откройте **Настройки** → **Templater**
2. Включите опцию **Trigger Templater on new file creation**
3. Убедитесь, что папка шаблонов указана как `template`

## Шаг 3: Использование

### Автоматическое создание через Daily Notes
- Нажмите горячую клавишу для Daily Notes (по умолчанию отсутствует, можно настроить)
- Или используйте команду: `Ctrl+P` → "Daily Notes: Open today's note"

### Ручное создание через Templater
1. `Ctrl+P` (или `Cmd+P` на Mac)
2. Введите "Templater: Create new note from template"
3. Выберите `Ежедневная заметка.md`

## Горячие клавиши

Рекомендуется настроить горячую клавишу для быстрого доступа:

1. **Настройки** → **Горячие клавиши**
2. Найдите "Daily Notes: Open today's note"
3. Назначьте удобную комбинацию (например, `Ctrl+D`)

## Альтернативный способ

Можно использовать команду календаря:
- Установите плагин Calendar
- Кликните на дату в календаре для создания/открытия заметки
