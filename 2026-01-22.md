## Заметки

### Реализация сервиса анализа ошибок документов

Создан сервис на Go 1.23 для анализа ошибок документов через API системы 1C-EDO.

#### Выполненные задачи:

1. **Инициализация проекта**
   - Создан `go.mod` с Go 1.23
   - Настроена структура проекта

2. **Модуль чтения CSV** (`csv_reader.go`)
   - Реализовано чтение ID документов из CSV файла в папке `/data`
   - Обработка заголовков и значений с кавычками

3. **Модуль авторизации** (`auth.go`)
   - Реализована авторизация на сайте https://hm.1c-edo.keydisk.ru/
   - Использование cookiejar для сохранения сессии
   - Поддержка различных статус кодов ответа

4. **HTTP клиент** (`client.go`)
   - Реализованы POST запросы к `/universal` с параметрами DataTables
   - Динамическая подстановка `ls_id` в фильтры

5. **Анализатор ошибок** (`analyzer.go`)
   - Парсинг JSON ответов
   - Проверка поля `peer_error` на наличие ошибок
   - Формирование структуры результатов

6. **Модуль сохранения результатов** (`result_writer.go`)
   - Сохранение результатов в CSV файл
   - Формат: ls_id, has_error, error_details

7. **Главный файл** (`main.go`)
   - Интеграция всех модулей
   - Последовательное выполнение: авторизация → чтение CSV → обработка документов → сохранение результатов
   - Обработка ошибок и логирование

8. **Документация**
   - Создан README.md с описанием проекта и инструкциями по использованию

#### Структура проекта:
- `main.go` - точка входа
- `auth.go` - авторизация
- `client.go` - HTTP клиент
- `csv_reader.go` - чтение CSV
- `analyzer.go` - анализ ошибок
- `result_writer.go` - сохранение результатов
- `config.go` - конфигурация
- `README.md` - документация

Проект успешно скомпилирован и готов к использованию.
